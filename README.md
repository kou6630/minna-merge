# みんなでマージ

商店街を舞台にしたマージゲーム。100×100マスの自分の盤面を、シャッターを開けながら広げていく。友達と同じサーバーで遊ぶと、みんなのカーソルが見える。カーソルはふだん光っていて、光っている同士がぶつかると2人ともスタミナ+20（そのあと2人とも15分は光らない）。
設計は [設計.md](設計.md)。ゲーム画面: https://kou6630.github.io/minna-merge/

## 友達と遊ぶ（サーバーを立てる人）

1. `サーバー起動.bat` をダブルクリック。初回だけ、サーバーの名前と合言葉を聞かれる（`config.json` に保存）。
2. 黒い画面に「★ 友達にはこの招待リンクを送ってください」と出る。リンクは自動でコピーされているので、
   LINE などに貼り付けて、合言葉と一緒に友達に送る。リンクはずっと同じ（裏で GitHub のシークレット Gist に今の住所を書いている）。
   **遊んでいる間は、黒い画面を閉じない**（閉じるとサーバーが止まる）。
3. 友達はリンクを開いて、初回だけ名前と合言葉を入れる。2回目からはゲーム画面を開いて、一覧から選ぶだけ。
4. やめるときは黒い画面で Ctrl+C を2回続けて押すか、画面を閉じる（保存してから止まる）。
   Ctrl+C を1回だけ押しても止まらない（コピーのつもりで押してしまっても大丈夫）。

- サーバーを立て直すと裏の住所は変わるが、招待リンクで入った人の画面は新しい住所を調べ直して自動でつながる（最大1分ほど）。
- サーバーが止まっていると、ゲーム画面に「サーバーが止まっているようです」と出る。

- 外からの接続は Cloudflare の一時トンネル（`tools/bin/cloudflared.exe`、アカウント不要）。無い場合は
  `gh release download -R cloudflare/cloudflared -p cloudflared-windows-amd64.exe -D tools/bin` で入れて `cloudflared.exe` に名前を変える。
- GitHub CLI（`gh`）にログインしていないと招待リンクは作れない。そのときは画面に出る直接アドレス（`wss://…`）を送る。
- ゲーム画面は `main` に push すると GitHub Actions がテストしてから GitHub Pages に公開する（`.github/workflows/pages.yml`）。

## いまできること（P4: 公開まで）

- `サーバー起動.bat` をダブルクリックするとサーバーが立つ。初回だけ、サーバーの名前と合言葉を聞かれる（`config.json` に保存）。
- ゲーム画面のタイトルにサーバー一覧が出る（オンラインかどうか・人数）。「入る」で、初回は名前と合言葉、2回目からは選ぶだけで入れる。
- 盤面は1人1枚。ほかの人のカーソル（どこを見ているか）だけが、リアルタイムで自分の画面に見える。
- 通信が切れても、自動でつなぎ直す。盤面と全員の進み具合は `save/world.json` に2秒ごとと終了時に保存する。
- 「ひとりで練習」で、サーバーなしでも遊べる（ブラウザに保存）。持ち主だけが使える: サーバー起動時に黒い画面へ出る
  「自分用リンク」（`?owner=…`、鍵は `config.json` の `ownerKey`）を一度開いたブラウザにだけボタンが出る。友達には送らない。
- ゲーム中は左上の「タイトルへ」でタイトル画面に戻れる。

- タイトルのサーバー一覧には、招待リンク・サーバーコード・直接アドレスのどれでも追加できる。

### 遊び方

- 発生器（パン窯など）をタップすると、エネルギーを使って周りにアイテムが出る。
- 同じアイテムどうしをドラッグで重ねると1段上がる。違うアイテムに落とすと入れ替わる。
- ほこりをかぶったアイテムは動かせない。同じアイテムを重ねるときれいになる。
- 経験値でレベルが上がり、発生器がもらえる。1つの系列は1つの発生器からだけ出る。
- 盤面のアイテム（発生器・プレゼント箱も）はタップするとまず選ぶだけ。枠が付き、下の枠に名前とレベルが出る。選んでいる発生器をもう一度タップすると出る（プレゼント箱は開く）。ドラッグはそのままできる。
  - Lv1 はゴミ箱（0コイン）、Lv2 からはコインに変えられる（Lv2=1、Lv3=2、Lv4=4、Lv5=6、Lv6=10、Lv7=14、Lv8=400。`scrapCoins`）。動いている発生器とプレゼント箱は消せない（発生器の部品はゴミ箱にできる。盤面が部品でいっぱいで動けなくならないように）。ふたの閉まったダンボールは「ダンボール」とだけ出て、中身は見えない。消したあと5秒だけ「元に戻す」が出る（`UNDO_SELL_MS`）。
  - 「i」でその種類の図鑑。Lv1 から3つずつ折り返して矢印でつなぐ。一度でも盤面に出た物（`Player.seen`）は絵と名前、まだの物はシルエットに「？」でレベルだけ。前のセーブは、盤面と倉庫にある物を見たことにして始める。
- 発生器は 9 段階。1〜2 段目は「部品」（青い設計図の上の材料・組み立て途中）で、合成して 3 段目になると動きだす。
  - 部品は、レベルアップ（2段目1個＋1段目2個＝ちょうど1台分）、ダンボール（奥の箱に1段目がたまに）、ストーリーの各章の 50% のプレゼント（1段目1個＋スタミナ（中））とクリア（2段目1個＋経験値・ジェム・スタミナ（大））でもらえる。
- 報酬でもらうアイテム（レベルアップとストーリーの発生器の部品・プレゼント箱）は、盤面に置かずに左下の「受け取り枠」にたまる。枠には次に出るアイテムの絵と、右上に残りの数が出る。タップすると、もらった順に1個ずつ、画面のまん中の近くの空きマスへ飛んで出る（盤面がいっぱいなら枠に残る）。
- ジェム（ストーリーのクリアでもらえる）の使い道は2つ。
  - スタミナ回復: 上のスタミナ表示を押す（スタミナ切れでタップしたときも自動で出る）。25ジェムで +50（満タンをこえてもよい）。
  - 発生器をすぐ満タン: 使い切って休んでいる自分の発生器を選んだときだけ「すぐ満タン」ボタンが出る（1回でも残っていれば出ない）。満タンの回数10回ごとに1ジェム（最低1）。
- 遊びと待ちのバランス（試算。無駄なく遊ぶ前提の目安）: 1〜3章は待ちなしで進み、4章から「スタミナを使い切ったら1時間半くらい待つ」が少しずつ増える（章ごとの待ち: 0 / 0 / 0 / 0 / 3 / 4 / 1 / 10 / 13 / 15 時間、10章でおよそ Lv45）。11〜20章は 17 / 18 / 19 / 19 / 20 / 21 / 22 / 23 / 24 / 15 時間（ジェムを全部スタミナに使うと 13〜18 時間）で、20章でレベルの上限 80。
  - そのための数値: レベルアップはスタミナ +20（満タン回復ではない）、経験値カーブは `xpToNext`、注文のコインは段階3から1段ごとに +30%（`orderCoins`）、ジェムは35で +50（`GEM_ENERGY_COST`）、発生器をすぐ満タンにするのは5ジェム（`GEN_REFILL_GEMS`）。章クリアの経験値はだれでも同じで、もとは「その章のころのレベルの半レベルぶん」で決めた値（レベルの上がり方を遅くしたので、今は半レベルより少ない。1章30・2章60・3章130・4章200・5章260・6章325・7章375・8章460・9章555・10章650。`packages/shared/src/story.ts`）。1回で上がるのは多くても1レベルで、マージをほとんどせずに進めたときだけ、そこで止まる（`cappedClearXp`）。どれも `packages/shared/src/defs.ts`。
  - 最初のパン窯だけは、すぐ遊べるように 3 段目で渡す。
- プレゼント箱（白 < 青 < 赤 < 紫）は合成できない。タップするたびに中身が1個出る。白・青は5回、赤・紫は3回まで必ず残り、そのあとはタップのたびに 50% で消える（ひびの入った「50%」の札が出て、箱と札が震える）。
  - 中身: 白=作れる子アイテムの段階2〜3、青=段階2〜5、赤=持っている発生器の段階1〜2、紫（キラキラ付き）=段階2〜4。
  - もらえる所: レベルアップで毎回白、2の倍数で青、3の倍数で赤、5の倍数で紫。ストーリーは決まった章の 50% で白か青、クリアで赤（`STORY_HALF_GIFTS` / `STORY_CLEAR_GIFTS`）。数値は `packages/shared/src/defs.ts` の `GIFTS`。

  | Lv | 発生器 | 出るもの |
  |---|---|---|
  | 1 | パン窯 | パン・ピザ |
  | 3 | ウォーターサーバー | 水〜ジュース |
  | 5 | 八百屋の木箱 | 野菜・果物 |
  | 8 | 喫茶のコーヒーメーカー | コーヒー・紅茶 |
  | 11 | 駄菓子屋のかご | 駄菓子 |
  | 14 | ケーキ屋のオーブン | お菓子 |
  | 17 | 花屋のバケツ | 花 |
  | 20 | 魚屋のトロ箱 | 魚・甲殻類 |
  | 24 | 雑貨屋の棚 | 雑貨・調理器具 |
  | 28 | 工具箱 | 工具 |
- 画面は横に 1:5。左の列が注文、右がマージ盤面。アイテムを注文カードへドラッグして納品し、そろうとコインと経験値がもらえる。
- ストーリーは20章。11〜20章は、広場からのびる北の道（画面の右上へ。花屋・本屋・ラーメン屋・おもちゃ屋・時計屋・和菓子屋と、つきあたりの夏祭りの広場）と西の道（画面の右下へ。八百屋・写真館・銭湯）。店主は新しい9人（カスミ・シゲルさん・リュウ・ハナエさん・ケンジさん・ゲンさん・ユウキ・トキオさん・サクラ）。
  - 中身（お店・人・会話・3択の家具・絵の指示）は `tools/assets/ch11_20.py` が元。`python -P tools/assets/build_ch11_20.py` で、ゲームのデータ（`packages/shared/src/story-ch11.ts`）と絵の指示（`r5_spec.json` の `r21-*`・`r21_spec.json`）を作る。
  - 置く家具や物は、角度のテスト（`tools/assets/check_angles.py`）を通った物だけ使う。型紙の箱（2:1・26.6°）と比べて、下辺（足元の左右の線の角度と角の位置）・横辺（左右の縦の線）・上辺（上の線の高さ）がすべて合っているか、テーブルや植木は床板の範囲からはみ出していないかを見る。`python -P tools/assets/angle_loop.py` で切り出し→テスト→合格した物を `angle_keep.json` に残し、不合格のあるシートを `angle_redo.txt` に出す。`python -P tools/assets/make_retry.py <回>` で不合格の物だけを集めた作り直しのシート（`r21-x<回>-*`）を作り、`node tools/assets/gen.mjs --force $(cat tools/assets/angle_retry.txt)` で作って、また angle_loop.py。全部合格するまでくり返す。置く場所と大きさは、絵の下の線を測らず、型紙の箱・床板の位置から決める（箱形の物は、足元の線が ±26.6° にそろえば絵の角で置く。10° までのずれは手前の角を中心に縦にずらしてそろえる。面が平らなので面ごと正しい向きになる）。テーブルと椅子の組は正面向きに描かれやすいので、11〜20章のテーブルは椅子なしの丸いテーブルにした。壁・床・ラグ・壁の絵・看板は、計算で正確な形に組み立てるのでずれない。
- 注文をくれるのはストーリーの登場人物8人（レイナとリョウジ以外、ストーリーに出てくる順: モモ・ゴロウさん・タクミ・ミサキ・ユリさん・ハルト・キヨさん・ダイゴ）。並んだ注文を全部納品すると、次の組がまとめて来る。最初は2人で、全部クリア2回ごとに1人ふえる。全部クリア3回ごとに、アイテムを2つ頼む人が1人ふえ、最後は8人全員が2個注文になる。
- 注文カードは、左にその人の腰から上の絵（`assets/orders/<key>.png`、画像生成）、右に頼まれたアイテム。盤面にもう出来ているアイテムは、注文の絵の右上と盤面のアイテムの右上に緑のチェックが付く（盤面の1個は注文の1つにだけ数える）。全部そろうと「完了」ボタンが出て、押すと盤面のアイテムをまとめて納品する（ドラッグで1つずつ渡すこともできる）。チェックのある人ほど上に並び、全部そろった人がいちばん上。注文の列はホイール・指・マウスのドラッグでスクロールでき、アイテムを運びながら列の上下の端に近づけてもスクロールする。
- 右下の倉庫ボタンへドラッグすると、自分だけの倉庫にしまえる（最初6枠、コインで12枠まで）。ボタンを押すと出し入れできる。発生器（部品も）やプレゼント箱も入れられ、発生器のチャージとプレゼント箱の開けた回数は覚えておく（出し入れで増やしたり回復したりできない。`Player.storageMeta`）。
- 開いた区画のマスはダンボールで埋まっている。最初に使えるのは左下の 2×2 の4マスだけで、そのとなりに半開きのダンボールが1つある。半開きは中のアイテムが見え、動かせないが、同じアイテムを重ねると合成されてそのマスが使えるようになり、上下左右のふたの閉まったダンボールが半開きになる。
- 1つの区画のダンボール25個は全部ちがう物。右上（外側）の区画ほど高い段階の物が入る（左下は段階1あたり、右上の角は段階7あたり）。
- 盤面は 5×5 マスのシャッターで閉じていて、左下の 5×5 から始まる。開いた所のとなりのシャッターに「このアイテムを○個」が出る。左の注文に同じアイテムを納品すると、そのシャッターの数が1つ進み、そろうと開いて土地が広がる（お客さんは、シャッターが待っているアイテムを多めに頼む）。
- サーバーで遊ぶとき、シャッターはみんなで共有（盤面とアイテムは1人1枚のまま）。だれかが納品すると全員のシャッターの数がすぐ進み、ほかの人の画面に「○○が○○を○個納品しました」と出る（続けて納品した分は少しまとめる）。数がそろうと、全員の盤面の同じ場所が同時に開く（中のダンボールは盤面ごと）。納品した人全員に +20 コイン。同じアイテムを待っているシャッターが2枚以上あるときは1枚ずつ進み（進んでいる方が先、並んだら最初の区画に近い方）、ほかの看板は灰色で「順番待ち」になる。ちがうアイテムのシャッターはそれぞれ進む（`activeShutter` / `waitingShutters`）。最初のシャッターは2段目のパン40個。そのあとは開けるほど量が増え、段階が上がると数は減る（`packages/shared/src/defs.ts` の `COMMON_FIRST_COUNT` / `COMMON_GROWTH` / `commonCount`、仕組みは `packages/shared/src/commons.ts`）。前のセーブは、だれかが開けていた区画をみんなで開けたことにして引きつぐ。「ひとりで練習」は今までどおり（自分だけのシャッター、3〜4個）。
- ほかの人のカーソルが名前付きで見え、運んでいるアイテムもついて動く。
- 右上のミニマップに、開いた区画・依頼（黄色）・ほかの人の居場所・今映している範囲が出る。押すとそこへ移動。
- 自分が作ったアイテムは売ってコインにできる。
- 何もない所をドラッグすると盤面が動く。拡大と縮小はホイールかピンチ。
- 「ひとりで練習」で `?debug` を付けて開くと、経験値・エネルギーのおためしボタンが出る。

## 動かす

Node.js 24 以上。入れるものはすべてこのフォルダの中に入る（npm のキャッシュも `.npm-cache/`）。

```
npm install
npm run server   # サーバー（localhost:8787）。サーバー起動.bat と同じ
npm run dev      # ゲーム画面 http://localhost:5181
npm test         # ルールとサーバーのテスト
npm run typecheck
npm run build    # apps/client/dist に出力
```

## 素材を作り直す

```
node tools/assets/gen.mjs items-veg --force   # Codex CLI（GPT-6-Luna / max）で1枚作り直す
python -P tools/assets/slice.py               # 切り出して apps/client/public/assets へ
```

## 構成

| パス | 内容 |
|---|---|
| `packages/shared/src/defs.ts` | 系列・発生器・レベルの定義表 |
| `packages/shared/src/engine.ts` | 盤面のルール（DOMなし。P1からはサーバーでも動かす） |
| `packages/shared/test/` | ルール・同期・注文と倉庫・シャッター・ダンボールのテスト |
| `packages/shared/src/sync.ts`・`protocol.ts` | 同期の道具（差分を当てる・差を取る）と通信メッセージ |
| `apps/server/src/` | サーバー（`room.ts` が本体、`main.ts` が起動） |
| `apps/server/test/` | 2人同時の同期・つかみの取り合い・再接続・保存のテスト |
| `apps/client/src/` | 画面（PixiJS）。`remote.ts` が通信、`local-server.ts` がひとりで練習、`title.ts` がサーバー一覧、`orders-ui.ts` が注文と倉庫、`minimap.ts` がミニマップ |
| `apps/server/src/publish.ts` | トンネルを開き、住所を Gist に書く |
| `tools/assets/` | 素材の生成（`gen.mjs`）と切り出し（`slice.py`） |
| `tools/bots/run.ts` | ボットで負荷と盤面のずれを試す（`node tools/bots/run.ts ws://localhost:8787 <合言葉> 10 30`） |
| `assets-src/raw/` | 生成したままのシート |

試験用に設定とセーブを分けたいときは `MINNA_HOME=.dev-server npm run server`（`.dev-server/` に作る）。
