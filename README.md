# みんなでマージ

商店街を舞台にしたマージゲーム。100×100マスの盤面を友達みんなで共有して遊ぶ。
設計は [設計.md](設計.md)。ゲーム画面: https://kou6630.github.io/minna-merge/

## 友達と遊ぶ（サーバーを立てる人）

1. `サーバー起動.bat` をダブルクリック。初回だけ、サーバーの名前と合言葉を聞かれる（`config.json` に保存）。
2. 黒い画面に「★ 友達にはこの招待リンクを送ってください」と出る。リンクは自動でコピーされているので、
   LINE などに貼り付けて、合言葉と一緒に友達に送る。リンクはずっと同じ（裏で GitHub のシークレット Gist に今の住所を書いている）。
   **遊んでいる間は、黒い画面を閉じない**（閉じるとサーバーが止まる）。
3. 友達はリンクを開いて、初回だけ名前と合言葉を入れる。2回目からはゲーム画面を開いて、一覧から選ぶだけ。
4. やめるときは黒い画面で Ctrl+C を2回続けて押すか、画面を閉じる（保存してから止まる）。
   Ctrl+C を1回だけ押しても止まらない（コピーのつもりで押してしまっても大丈夫）。

- サーバーを立て直すと裏の住所は変わるが、招待リンクで入った人の画面は新しい住所を調べ直して自動でつながる（最大1分ほど）。
- サーバーが止まっていると、ゲーム画面に「サーバーが止まっているようです」と出る。

- 外からの接続は Cloudflare の一時トンネル（`tools/bin/cloudflared.exe`、アカウント不要）。無い場合は
  `gh release download -R cloudflare/cloudflared -p cloudflared-windows-amd64.exe -D tools/bin` で入れて `cloudflared.exe` に名前を変える。
- GitHub CLI（`gh`）にログインしていないと招待リンクは作れない。そのときは画面に出る直接アドレス（`wss://…`）を送る。
- ゲーム画面は `main` に push すると GitHub Actions がテストしてから GitHub Pages に公開する（`.github/workflows/pages.yml`）。

## いまできること（P4: 公開まで）

- `サーバー起動.bat` をダブルクリックするとサーバーが立つ。初回だけ、サーバーの名前と合言葉を聞かれる（`config.json` に保存）。
- ゲーム画面のタイトルにサーバー一覧が出る（オンラインかどうか・人数）。「入る」で、初回は名前と合言葉、2回目からは選ぶだけで入れる。
- 全員が同じ盤面を見て、同じアイテムを触る。ほかの人のタップ・マージ・移動がすぐ届く。ほかの人が持っているアイテムは薄く表示され、つかめない。
- 通信が切れても、自動でつなぎ直す。盤面と全員の進み具合は `save/world.json` に2秒ごとと終了時に保存する。
- 「ひとりで練習」で、サーバーなしでも遊べる（ブラウザに保存）。

- タイトルのサーバー一覧には、招待リンク・サーバーコード・直接アドレスのどれでも追加できる。

### 遊び方

- 発生器（パン窯など）をタップすると、エネルギーを使って周りにアイテムが出る。
- 同じアイテムどうしをドラッグで重ねると1段上がる。違うアイテムに落とすと入れ替わる。
- ほこりをかぶったアイテムは動かせない。同じアイテムを重ねるときれいになる。
- 経験値でレベルが上がる。Lv3 でお菓子、Lv5 で八百屋の木箱、Lv10 で花屋のバケツ…と、出せるものが増える。
- 画面の下にお客さんの注文が3件。アイテムをカードへドラッグして納品し、そろうとコインと経験値がもらえる。
- 右下の倉庫ボタンへドラッグすると、自分だけの倉庫にしまえる（最初6枠、コインで12枠まで）。ボタンを押すと出し入れできる。
- 閉じた区画のシャッターに「みんなの依頼」の看板が出る。アイテムを看板へドラッグして、みんなで納品する。そろうとシャッターが上がって土地が広がる。
- ほかの人のカーソルが名前付きで見え、運んでいるアイテムもついて動く。
- 右上のミニマップに、開いた区画・依頼（黄色）・ほかの人の居場所・今映している範囲が出る。押すとそこへ移動。
- 自分が作ったアイテムは売ってコインにできる。
- 何もない所をドラッグすると盤面が動く。拡大と縮小はホイールかピンチ。
- 「ひとりで練習」で `?debug` を付けて開くと、経験値・エネルギーのおためしボタンが出る。

## 動かす

Node.js 24 以上。入れるものはすべてこのフォルダの中に入る（npm のキャッシュも `.npm-cache/`）。

```
npm install
npm run server   # サーバー（localhost:8787）。サーバー起動.bat と同じ
npm run dev      # ゲーム画面 http://localhost:5181
npm test         # ルールとサーバーのテスト
npm run typecheck
npm run build    # apps/client/dist に出力
```

## 素材を作り直す

```
node tools/assets/gen.mjs items-veg --force   # Codex CLI（GPT-6-Luna / max）で1枚作り直す
python -P tools/assets/slice.py               # 切り出して apps/client/public/assets へ
```

## 構成

| パス | 内容 |
|---|---|
| `packages/shared/src/defs.ts` | 系列・発生器・レベルの定義表 |
| `packages/shared/src/engine.ts` | 盤面のルール（DOMなし。P1からはサーバーでも動かす） |
| `packages/shared/test/` | ルール・同期・注文と倉庫・みんなの依頼のテスト |
| `packages/shared/src/sync.ts`・`protocol.ts` | 同期の道具（差分を当てる・差を取る）と通信メッセージ |
| `apps/server/src/` | サーバー（`room.ts` が本体、`main.ts` が起動） |
| `apps/server/test/` | 2人同時の同期・つかみの取り合い・再接続・保存のテスト |
| `apps/client/src/` | 画面（PixiJS）。`remote.ts` が通信、`local-server.ts` がひとりで練習、`title.ts` がサーバー一覧、`orders-ui.ts` が注文と倉庫、`minimap.ts` がミニマップ |
| `apps/server/src/publish.ts` | トンネルを開き、住所を Gist に書く |
| `tools/assets/` | 素材の生成（`gen.mjs`）と切り出し（`slice.py`） |
| `tools/bots/run.ts` | ボットで負荷と盤面のずれを試す（`node tools/bots/run.ts ws://localhost:8787 <合言葉> 10 30`） |
| `assets-src/raw/` | 生成したままのシート |

試験用に設定とセーブを分けたいときは `MINNA_HOME=.dev-server npm run server`（`.dev-server/` に作る）。
